# Release Notes

Version v2.4.3 — April 11, 2026

## Windows Light Theme Icon

The tray and taskbar icon now adapts to your Windows theme. If you're using light mode, you'll see a black icon instead of the white one disappearing into a white taskbar. Switches automatically if you change your theme while the app is running. Linux stays on the white icon since desktop environments don't report theme reliably.
